# Экран: проект

Маршрут `/projects/<slug>`. Внутри оболочки.
Истории — US-12 … US-18, US-20, US-22, US-31, US-34.
Общие соглашения — [README.md](./README.md).

## Назначение и главный сценарий

Главный сценарий — **попасть в нужную очередь**. Всё остальное (участники, приглашения,
настройки) — обслуживание, к которому обращаются редко. Отсюда раскладка: очереди
на первой вкладке и видны сразу, администрирование убрано за вкладки.

## D-04: две ссылки, которые нельзя перепутать

Это самое опасное место экрана. Смешение «адреса проекта» и «ссылки-приглашения»
означает утечку доступа: человек копирует то, что считает адресом, кидает в общий чат —
и раздаёт членство в проекте ([D-04](../../product/decisions.md#d-04)).

Разведены **по семи признакам сразу**. Ни один из них не является единственным носителем.

| Признак | Адрес проекта | Ссылка-приглашение |
|---|---|---|
| **Где живёт** | шапка проекта, видна всегда, всем участникам | только вкладка «Приглашения», только у администратора |
| **Как выглядит** | текстовая кнопка, нейтральный `textSecondary`, без заливки | строка в списке приглашений с явной плашкой роли и срока |
| **Иконка** | `link_rounded` — звено цепи | `person_add_alt_1_rounded` — человек со знаком «плюс» |
| **Глагол** | «Скопировать адрес проекта» | «Создать приглашение» → «Скопировать ссылку-приглашение» |
| **Число шагов** | одно нажатие | выбрать роль → выбрать срок → создать → скопировать |
| **Что написано рядом** | «Ссылка не даёт доступа: откроется только у участников проекта» | «По этой ссылке любой, кто её откроет, войдёт в проект как участник» |
| **Подтверждение при копировании** | нет, просто тост «Адрес скопирован» | тост-`warning`: «Ссылка-приглашение скопирована. По ней в проект войдёт любой, у кого она окажется» |

Дополнительно:

- слово «приглашение» **никогда** не появляется рядом с кнопкой адреса, и наоборот —
  слово «адрес» не появляется в блоке приглашений;
- обе кнопки **никогда не находятся в одной визуальной группе** и никогда не видны
  одновременно: чтобы увидеть приглашения, надо переключить вкладку;
- у ссылки-приглашения нет «быстрого копирования» из шапки, из меню «⋯» и из списка
  участников. Единственная точка — вкладка «Приглашения».

## Вкладка «Очереди»

Строка очереди — плотная, высота 44:

```
+------------------------------------------------------------------+
| DEV   Разработка                                       12 задач   |
+------------------------------------------------------------------+
  ^     ^                                                ^
  ключ  название, bodyS textPrimary, ellipsis            число незавершённых,
  bodySStrong accent, ширина 56, tabular                 label textMuted
```

- Разделитель — нижняя граница `borderSubtle`. Сортировка по названию (US-31).
- Счётчик — задачи со статусом **не** категории `done` (US-31). Подпись «12 задач»
  со склонением («1 задача», «3 задачи», «12 задач»).
- Клик по строке → `/queues/DEV`.
- Описание очереди в строке не показывается: оно нужно внутри очереди, а не в списке.
- «Создать очередь» — кнопка `md` `primary` под списком, **только администратор** (US-30).
- Меню «⋯» в строке (только админ): «Изменить», «Удалить».
  «Удалить» — вариант `dangerGhost`; при непустой очереди действие приводит
  к модалке-отказу: «Сначала удалите задачи очереди» ([D-24](../../product/decisions.md#d-24)).

## Вкладка «Участники»

Строка участника, высота 48:

```
+---------------------------------------------------------------------+
| [АИ] Анна Иванова  (вы)          anna@example.com   Админ    [⋯]    |
|      в проекте с 12 фев                                             |
+---------------------------------------------------------------------+
```

| Элемент | Токены |
|---|---|
| Аватар | `sm` (24) |
| Имя | `bodyS` `textPrimary`; пометка «(вы)» — `label` `textMuted` |
| «в проекте с …» | `label` `textMuted`, вторая строка (US-14) |
| Email | `bodyS` `textMuted`, колонка 220, `ellipsis` посередине |
| Роль | бейдж роли (`components.md` 7), колонка 96 |
| «⋯» | только администратору: «Сделать администратором» / «Сделать участником» / «Сделать читателем», разделитель, «Исключить из проекта» (`dangerGhost`) |

- Список виден всем участникам, включая читателя (US-14).
- Поиска и фильтров нет: участников 3–15 (US-14, вне объёма).
- Сортировка: администраторы первыми, дальше по имени.
- Текущий пользователь помечен «(вы)» — текстом, не цветом.

### Особые случаи

| Случай | Поведение |
|---|---|
| Последний администратор | пункты понижения роли и «Исключить» отсутствуют; вместо них в меню строка-пояснение `label` `textMuted`: «В проекте должен остаться хотя бы один администратор» |
| Админ понижает сам себя | модалка подтверждения: «После этого вы потеряете управление проектом». После применения вкладки «Приглашения» и «Настройки» **исчезают без перезагрузки** (US-15) |
| Исключение участника | модалка подтверждения с последствиями: «Задачи, где <Имя> исполнитель, останутся без исполнителя» (US-16). Кнопка `danger` |
| Новый участник вступил по приглашению | появляется в списке в течение 5 с без перезагрузки (US-21), фон строки на 1200 мс `accentSurface` |
| Ошибка смены роли (409) | тост-ошибка + откат бейджа к прежней роли |

### Состояния вкладки «Участники»

Загрузка — 5 строк-скелетонов по 48. Пусто — невозможно: в проекте всегда есть минимум
один администратор (`permissions.md`, п. 7). Ошибка — «Не удалось загрузить участников»
+ «Повторить». Длинное имя или email — `ellipsis` + тултип.

## Вкладка «Приглашения» (только администратор)

```
+------------------------------------------------------------------------------+
| ⓘ  Ссылка-приглашение даёт членство в проекте. Любой, кто её откроет,        |
|    войдёт в проект с указанной ролью. Это не адрес проекта.                  |  баннер info
+------------------------------------------------------------------------------+
                                                        [+ Создать приглашение]
+------------------------------------------------------------------------------+
| Участник · 7 дней  · до 19 фев   · вступили: 2   [Скопировать ссылку] [⋯]    |  56
| создал: Анна Иванова, 12 фев                                                 |
+------------------------------------------------------------------------------+
| Читатель · 30 дней · до 14 мар   · вступили: 0   [Скопировать ссылку] [⋯]    |  56
| создал: Анна Иванова, 12 фев                                                 |
+------------------------------------------------------------------------------+
| Участник · истекло 5 фев         · вступили: 4                          [⋯]  |  56
| создал: Пётр Смирнов, 29 янв                              (приглушено 60 %)  |
+------------------------------------------------------------------------------+
```

- **Баннер `info` вверху обязателен** — он и есть основная защита от путаницы с адресом
  проекта. Не сворачивается и не скрывается.
- Состояние приглашения — плашка + текст, как статус задачи (цвет не единственный носитель):
  «Действует» (`successSurface`), «Истекло» (`surfaceSunken`), «Отозвано» (`dangerSurface`).
- «Скопировать ссылку» есть только у действующих. У истёкших и отозванных кнопки нет
  (US-22: повторно активировать нельзя).
- «⋯»: «Отозвать» (`dangerGhost`) — только у действующих.
- Истёкшие и отозванные остаются в списке приглушёнными (US-22).

### Модалка «Создать приглашение» (`sm`, 400)

```
+------------------------------------------+
| Создать приглашение                 [×]  |
+------------------------------------------+
| Роль для тех, кто вступит                |
| ( ) Участник — работает с задачами       |  радиокнопки
| ( ) Читатель — только смотрит            |
|                                          |
| Срок действия                             |
| [ 1 день ] [ 7 дней ] [ 30 дней ]        |  сегментированный выбор, по умолчанию 7
|                                          |
| ⚠ По этой ссылке в проект войдёт любой,  |  баннер warning
|   у кого она окажется.                   |
+------------------------------------------+
|                [ Отмена ] [ Создать ]    |
+------------------------------------------+
```

Роли «Администратор» в списке нет ([D-05](../../product/decisions.md#d-05)).
Бессрочных приглашений нет (US-20).

После создания модалка **не закрывается**, а показывает готовую ссылку в поле
только для чтения с кнопкой «Скопировать» — иначе пользователь теряет ссылку
и создаёт вторую. Тост при копировании — `warning`, с текстом из таблицы D-04.

## Вкладка «Настройки» (только администратор)

Секции сверху вниз, каждая с заголовком `title` и отступом `space6`:

1. **Название и описание.** Поле `md` + многострочное поле. Сохранение — кнопка
   «Сохранить» под секцией, активна только при изменениях.
2. **Обложка.** Превью 240 × 135, кнопки «Загрузить» и «Удалить». Ограничения
   написаны рядом, до выбора файла: «PNG, JPEG или WEBP, до 5 МБ» (US-12).
   Ошибка типа или размера — баннер под секцией, прежняя обложка остаётся.
3. **Короткое имя в адресе** — см. ниже.
4. **Удаление проекта** — «опасная зона», см. ниже.

### Короткое имя в адресе (US-18)

```
Короткое имя в адресе
+--------------------------------------------------+
| sladkiy-limit                                    |  поле md, mono 13
+--------------------------------------------------+
Адрес проекта будет: https://tracker.example/projects/sladkiy-limit
                                                       ^ предпросмотр, mono, textSecondary

⚠ Адрес изменится. Ранее отправленные ссылки продолжат открывать проект,
  но в браузере будет показываться новый адрес.
```

- Поле принимает только строчные латинские буквы, цифры и дефис. Ввод кириллицы,
  пробелов и заглавных **приводится к допустимому виду на лету**, результат сразу виден
  в поле (US-18): пользователь печатает «Сладкий Лимит» — в поле появляется
  `sladkiy-limit`. Молчаливое отбрасывание символов запрещено: подпись под полем
  поясняет «Только строчные латинские буквы, цифры и дефис».
- Предпросмотр полного адреса обновляется по мере ввода.
- Предупреждение (`warning`-баннер) показывается **только когда значение изменено**
  относительно сохранённого, а не постоянно.
- Занято (409): ошибка у поля «Такой адрес уже занят» — без указания, каким проектом.
- Системное имя (`issues`, `invite`, `projects`, `profile`, `api`): «Этот адрес
  зарезервирован приложением».
- В UI слово «слаг» не используется нигде (`glossary.md`).

### Опасная зона

Секция отделена сверху границей 1 px `border` и отступом `space8`.
Заголовок «Удаление проекта» — `title` `danger`.

Модалка удаления (`sm`): перечисление того, что будет удалено (очереди, задачи,
комментарии, вложения), поле «Введите название проекта для подтверждения»,
кнопка «Удалить проект» (`danger`) неактивна, пока введено не точное название (US-17).
Фокус при открытии — на поле ввода, не на кнопке.

| **Много очередей / участников / приглашений** | см. состояния вкладок |
| **Очень длинный текст** | название проекта — `ellipsis` + тултип; описание в шапке — одна строка, полный текст по раскрытию; email — обрезка посередине |

## Доступность

- Вкладки — стандартный таб-паттерн (`TabBar` даёт роли и `←`/`→` сам).
  Счётчик входит в доступное имя: «Участники, 5».
- Строка очереди читается как «DEV, Разработка, 12 задач, открыть».
- Бейдж роли — текст, а не только цвет; пометка «(вы)» — текст.
- Состояние приглашения — плашка с текстом; «Истекло» не передаётся одной лишь
  приглушённой непрозрачностью, у него есть подпись.
- Кнопка «Скопировать адрес»: доступное имя «Скопировать адрес проекта.
  Ссылка не даёт доступа». Пояснение — часть имени, а не только тултип:
  для незрячего пользователя визуальная подпись рядом бесполезна.
- Кнопка «Скопировать ссылку-приглашение»: доступное имя
  «Скопировать ссылку-приглашение. По ней в проект войдёт любой, у кого она окажется».
  Разведение D-04 обязано работать и в скринридере, иначе оно не работает.
- Результат копирования объявляется через `liveRegion` (тост).
- Опасная зона: кнопка удаления имеет доступное имя «Удалить проект, необратимо».

| Нормализация короткого имени на лету | `TextInputFormatter` со своей логикой | **кастом**, ~50 строк; правила — D-35 |
| Загрузка обложки | выбор файла через `file_selector`/`image_picker` для веба | внешняя зависимость, проверить |
| Условный набор вкладок по роли | пересборка `TabController` при смене роли | **осторожно**: смена длины `TabController` на лету — известный источник исключений, нужен `key` на всём блоке |
