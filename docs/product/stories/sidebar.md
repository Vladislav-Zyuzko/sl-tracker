# Сайдбар: активные задачи и поиск (US-80 … US-83)

Блок 10 MVP. Сайдбар отвечает на единственный вопрос: «что я делаю прямо сейчас».
Определение активной задачи — [D-19](../decisions.md#d-19) и [glossary.md](../glossary.md).

---

## US-80. Постоянный сайдбар

**Как** пользователь трекера
**я хочу** всегда иметь под рукой боковую панель,
**чтобы** переключаться между своими задачами, не возвращаясь на главный экран.

### Критерии приёмки
- [ ] Сайдбар присутствует на всех экранах приложения после входа: списки проектов, проект,
      очередь, задача, профиль.
- [ ] Сайдбар содержит в этом порядке: переход к списку проектов, поиск, список активных
      задач текущего пользователя.
- [ ] Сайдбар можно свернуть; выбранное состояние сохраняется между визитами.
- [ ] На узком экране (мобильный браузер) сайдбар открывается поверх контента и закрывается
      после перехода по ссылке. Точные брейкпоинты — за дизайнером.
- [ ] Сайдбар не перекрывает содержимое страницы задачи на широком экране.

### Не входит в объём
- Настройка состава сайдбара, произвольные разделы, закреплённые фильтры.
- Изменение ширины сайдбара перетаскиванием.

## US-81. Список моих активных задач

**Как** участник команды
**я хочу** видеть слева свои незакрытые задачи,
**чтобы** сразу понимать свой объём работы и быстро в них переходить.

*Если этого нет:* каждое утро придётся обходить все проекты и очереди руками.

### Критерии приёмки
- [ ] В список попадают задачи, где текущий пользователь — исполнитель, и статус задачи
      **не** относится к категории `done`. Других условий нет.
- [ ] Задачи собираются из всех проектов и очередей, где пользователь состоит; принадлежность
      к проекту/очереди видна в строке (как минимум по ключу задачи).
- [ ] Каждая строка показывает ключ и название задачи; при нехватке места название
      обрезается, ключ — никогда.
- [ ] Список отсортирован по убыванию приоритета, при равенстве — сначала недавно изменённые.
- [ ] Нажатие на строку открывает задачу; текущая открытая задача выделена в списке.
- [ ] Список обновляется после действий пользователя, меняющих его состав: назначение
      задачи на себя, снятие с себя, перевод задачи в «Закрыт» и обратно — не позднее
      чем через 5 секунд, без перезагрузки страницы.
- [ ] Если активных задач нет, показывается пустое состояние «Нет активных задач»
      с коротким пояснением, что сюда попадают задачи, где вы исполнитель.
- [ ] Список остаётся отзывчивым при 200+ активных задачах (виртуализация — требование
      `CLAUDE.md`).
- [ ] Число активных задач показано рядом с заголовком списка.

### Не входит в объём
- Задачи, где пользователь автор или комментатор, — их в сайдбаре нет.
- Группировка по проектам, ручная сортировка, скрытие отдельных задач.
- Задачи из проектов, откуда пользователя исключили (пропадают автоматически).

## US-82. Поиск по активным задачам

**Как** участник команды с двумя десятками задач
**я хочу** быстро отфильтровать свой список по названию или ключу,
**чтобы** попасть в нужную задачу за пару секунд.

### Критерии приёмки
- [ ] Строка поиска расположена в сайдбаре над списком активных задач.
- [ ] Поиск фильтрует **только** список активных задач текущего пользователя
      ([D-20](../decisions.md#d-20)); чужие и закрытые задачи в результатах не появляются.
- [ ] Поиск идёт по подстроке в названии и по ключу задачи, без учёта регистра:
      запрос `авто` находит «Автоматизация отчёта», запрос `dev-4` находит `DEV-42`.
- [ ] Результаты обновляются по мере ввода, не позднее 300 мс после остановки набора.
- [ ] Пустой запрос показывает полный список активных задач.
- [ ] Если ничего не найдено, показывается «Ничего не найдено среди ваших активных задач»
      с пояснением, что поиск ищет только по ним.
- [ ] Плейсхолдер поля явно говорит об области поиска (например, «Поиск по моим активным
      задачам») — чтобы поиск не выглядел сломанным ([D-20](../decisions.md#d-20)).
- [ ] Поле очищается кнопкой и клавишей Esc.

### Не входит в объём
- Поиск по описанию, комментариям, вложениям.
- Глобальный поиск по всем задачам и проектам, экран результатов поиска — релиз 2
  (подтверждено пользователем: в MVP не входит).
- История поисковых запросов, подсказки, нечёткий поиск и опечатки.

## US-83. Быстрый переход к последним просмотренным задачам

**Как** пользователь, который переключается между задачами
**я хочу** вернуться к задаче, которую только что смотрел,
**чтобы** не искать её заново.

> Приоритет: **низкий**. Берётся в MVP только если блок 10 закрыт раньше срока;
> иначе переносится в релиз 2. Без этой истории продукт полноценен.

### Критерии приёмки
- [ ] В сайдбаре под списком активных задач показаны до 5 последних открытых пользователем
      задач, в порядке от недавних к старым.
- [ ] В список попадают любые задачи, которые пользователь открывал, включая закрытые
      и те, где он не исполнитель.
- [ ] Задача, к которой пользователь потерял доступ (исключён из проекта, задача удалена),
      из списка исчезает.
- [ ] Список сохраняется между визитами в пределах одного браузера.

### Не входит в объём
- Синхронизация истории просмотров между устройствами.
- Закрепление задач вручную.
