# Очереди (US-30 … US-34)

Блок 4 MVP. Очередь — пространство задач одного рода внутри проекта; она владеет ключом
и набором статусов. Термины — [glossary.md](../glossary.md).

---

## US-30. Создание очереди

**Как** администратор проекта
**я хочу** создать очередь с коротким ключом,
**чтобы** задачи получали читаемые ключи вида `DEV-1`.

*Если этого нет:* задачи создать невозможно — ключ задачи выдаёт именно очередь.

### Критерии приёмки
- [ ] Создать очередь может только администратор проекта; участник и читатель не видят кнопку,
      прямой вызов API возвращает 403.
- [ ] Обязательные поля: название очереди (1–100 символов) и ключ. Описание — необязательно,
      до 1000 символов, Markdown.
- [ ] Ключ принимается только в виде латинских заглавных букв и цифр, 2–10 символов, первый
      символ — буква (`^[A-Z][A-Z0-9]{1,9}$`). Ввод строчных букв автоматически приводится
      к заглавным; пробелы, кириллица и спецсимволы не вводятся.
- [ ] Форма показывает предпросмотр будущего ключа первой задачи: «Задачи будут выглядеть
      так: `DEV-1`».
- [ ] Ключ проверяется на уникальность **по всему трекеру**, а не внутри проекта. Занятый ключ
      даёт ошибку «Такой ключ уже занят, выберите другой» — без указания, в каком проекте
      он занят. Серверный ответ — 409.
- [ ] Проверка занятости ключа происходит до отправки формы (при вводе), и повторно на сервере
      при сохранении.
- [ ] Ключи удалённых очередей не выдаются повторно ([D-25](../decisions.md#d-25)).
- [ ] Форма предупреждает, что ключ нельзя изменить после создания.
- [ ] Сразу после создания очередь содержит пять статусов по умолчанию
      (см. [workflow](./workflow.md), US-60) и ноль задач.
- [ ] После создания пользователь попадает в очередь и видит пустое состояние с кнопкой
      «Создать задачу».

### Не входит в объём
- Изменение ключа очереди ([D-06](../decisions.md#d-06)).
- Настройка статусов, полей, шаблонов и прав на уровне очереди.
- Перенос очереди в другой проект.

## US-31. Список очередей проекта

**Как** участник проекта
**я хочу** видеть очереди проекта,
**чтобы** попасть в нужный поток задач.

### Критерии приёмки
- [ ] На странице проекта показан список очередей: ключ, название и число незавершённых задач
      (статус не в категории `done`).
- [ ] Список виден всем участникам проекта, включая читателя.
- [ ] Очереди отсортированы по названию по возрастанию.
- [ ] Если очередей нет, показывается пустое состояние; кнопка «Создать очередь» видна только
      администратору, остальным показывается пояснение «Очередей пока нет».
- [ ] Очереди проекта доступны из сайдбара при нахождении внутри проекта.

### Не входит в объём
- Избранные очереди, ручной порядок, скрытие очередей.

## US-32. Список задач очереди

**Как** участник проекта
**я хочу** видеть задачи очереди списком,
**чтобы** понимать состояние работы и находить нужную задачу.

### Критерии приёмки
- [ ] Список показывает: ключ, название, статус, приоритет, сложность и аватар исполнителя
      (или пометку «Не назначен»).
- [ ] По умолчанию список отсортирован по убыванию приоритета, при равном приоритете —
      по убыванию номера задачи ([D-28](../decisions.md#d-28)).
- [ ] Пользователь может переключить сортировку на «Сначала новые» (по убыванию номера).
- [ ] Есть фильтр по статусу: можно выбрать один или несколько статусов очереди; выбранный
      фильтр отражён в адресе страницы, чтобы ссылку на отфильтрованный список можно было
      скопировать.
- [ ] Список подгружается порциями при прокрутке; на очереди с 1000 задач страница остаётся
      отзывчивой, прокрутка не «дёргается» (виртуализация — требование `CLAUDE.md`).
- [ ] Нажатие на строку открывает задачу по адресу `/issues/DEV-42`.
- [ ] Пустая очередь показывает пустое состояние с кнопкой «Создать задачу» (у участника
      и администратора) или пояснением (у читателя).

### Не входит в объём
- Группировка, произвольные фильтры (по исполнителю, автору, приоритету), сохранённые
  представления, канбан-доска — релиз 2.
- Массовые операции над задачами, экспорт списка.

## US-33. Переименование очереди

**Как** администратор проекта
**я хочу** изменить название и описание очереди,
**чтобы** исправить формулировку, не трогая ключ.

### Критерии приёмки
- [ ] Администратор может изменить название и описание очереди.
- [ ] Поле ключа в форме редактирования отображается, но недоступно для ввода, с пояснением
      «Ключ очереди изменить нельзя».
- [ ] Изменение названия не влияет на ключи существующих задач.
- [ ] Участник и читатель не видят форму редактирования; прямой вызов API возвращает 403.

### Не входит в объём
- Изменение ключа, слияние очередей.

---

## US-34. Удаление очереди

**Как** администратор проекта
**я хочу** удалить очередь, созданную по ошибке,
**чтобы** она не мешала в списке.

### Критерии приёмки
- [ ] Удаление доступно только администратору проекта.
- [ ] Удалить можно только очередь без задач. При наличии хотя бы одной задачи (в любом
      статусе) действие блокируется с сообщением «Сначала удалите задачи очереди»;
      серверный ответ — 409 ([D-24](../decisions.md#d-24)).
- [ ] Удаление требует подтверждения в диалоге.
- [ ] После удаления очередь исчезает из списка у всех участников проекта; её ключ остаётся
      занятым и не может быть использован для новой очереди.

### Не входит в объём
- Каскадное удаление задач вместе с очередью.
- Архивирование очереди — кандидат в релиз 2.
- Перенос задач в другую очередь перед удалением ([D-14](../decisions.md#d-14)).
