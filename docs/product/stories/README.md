## Как читать критерии приёмки

- Каждый пункт — проверяемое поведение: QA должен уметь прогнать его руками или тестом.
- Раздел «Не входит в объём» так же обязателен, как и критерии: он защищает границу MVP.
- Права в критериях приёмки всегда согласованы с [../permissions.md](../permissions.md).
  Если критерий противоречит матрице прав — прав документ по правам, а история правится.
- Термины — только из [../glossary.md](../glossary.md).

US-75…79, US-84…89, US-93…99, US-105…109) оставлены для доращивания соответствующих блоков.
Занятые во второй редакции: US-05, US-06 (список доступа), US-18 (короткое имя в адресе),
US-74 (упоминания), US-104 (уведомление об упоминании). В третьей: US-07 (экран управления
доступом), US-08 (приватность упоминаний), US-09 (отзыв доступа).
Истории релизов 2 и 3 нумеруются с US-200.
